IMAGE-TO-VIDEO (Ken Burns)
  npm run agentic:image to-video --input shot.png --duration 5 --kenburns --text "Built by students"
  npm run agentic:image to-video --input shot.png --duration 3 --output clip.mp4

  Creates 1920x1080 video with slow zoom/pan + optional text overlay.
  Perfect for creating motion from still photos when no video clip is available.

EXAMPLES
  npm run agentic:image convert --input shot.png --output shot.jpg
  npm run agentic:image resize --input shot.png --w 1080 --h 1920
  npm run agentic:image text --input shot.png --text "Free for students" --color white --position bottom
  npm run agentic:image watermark --input shot.png --overlay logo.png --position top-left --opacity 0.7
  npm run agentic:image tint --input shot.png --color "#FF6600@0.3"
  npm run agentic:image round-corners --input shot.png --radius 20 --output rounded.png
  npm run agentic:image to-video --input shot.png --duration 5 --kenburns --output clip.mp4

QC CHECKLIST
  - Verify dimensions: npm run agentic:image info -- --input <file>
  - Check output format and size
  - Vision-inspect for artifacts, text clipping, or color issues
