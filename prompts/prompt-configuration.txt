VIDEO TYPE TEMPLATES (built-in, configured in src/agentic/config.ts)

These presets are applied on top of your base preset, then your explicit
overrides win last:

  facts:        Fade transition, cinematic grade, mid music, kinetic text, J-cut 0.4s
  tutorial:     Slide transition, neutral grade, calm music, kinetic text, J-cut 0.2s
  news:         Cut transition, cool grade, mid music, landscape, no kinetic text
  story:        Fade transition, warm grade, calm music, kinetic text, J-cut 0.6s
  product:      Slide transition, vivid grade, energetic music, SFX on cuts
  motivational: Zoomblur transition, cinematic grade, energetic music, karaoke captions
  nature:       Fade transition, neutral grade, calm music, no kinetic text

ADVANCED AI VERIFICATION (opt-in)

  "aiVerify": {
    "enabled": true,
    "minConfidence": 0.7,
    "verifyOnAcquire": true,     // Check downloaded assets
    "verifyOnApprove": true,     // Gate before render
    "verifyOnEdit": true,        // Check after edits
    "verifyOnRender": true,      // Check final output
    "finalMode": "vision",       // signal | vision
    "checkSubjectMatch": true,   // Does visual match script topic?
    "checkWatermark": true,      // Detect unwanted watermarks
    "checkSafety": true,         // NSFW / violent content check
    "checkMusicMood": true,      // Does music match intended mood?
    "checkSpeechClarity": true,  // Is voiceover clear?
    "checkBackgroundNoise": true // Unwanted noise in audio
  }
